# 班主任工作台

> 给小学班主任用的**正面管教成长记录**工具。纯前端、离线可用，**数据只存本机、不联网不上传**。

选学生 → 点标签 → 写评语，约 30 秒记一条；期末一键导出成长记录文本，交给自己的 AI 工具做分析。没有账号、没有后端、不发起任何网络请求，依赖与图标全部为本地资源。

## 功能

| Tab | 能做什么 |
| --- | --- |
| ✍️ **记录** | 选学生 → 点标签 → 写评语，约 30 秒一条；每条最多 6 张图片（拍照 / 相册）；时间线分页加载，可切卡片 / 缩略图 / 紧凑版式；草稿自动保存，误退不丢 |
| 🗂️ **班务** | 本班课表（夏 / 冬作息，可选单双周）＋ 我的课表（跨班任教自填）；收缴任务（点姓名即标记已交 / 未交） |
| 📊 **分析** | 一键生成本学期成长记录文本（实名，可选是否并入「关注」类内部观察），复制或下载后交给你自己的 AI 工具 |
| 🔒 **数据** | 名单 / 分类 / 标签库管理、学期管理与归档、备份与恢复、回收站、设置 |

**标签体系**：正面管教 8 个能力分类（各 6 个标签）＋「关注」内部观察分类（问题行为 10 / 错误目的 4 / 鼓励支持 8），共 **70 个预设标签**，分类与标签均可增删改名。

## 数据安全

- **自动备份**：每次打开应用在本机留一份滚动快照（与业务库隔离，最多保留 3 份）。
- **损坏抢救**：数据库打开失败时，先尽力把可读数据抢救出来再重建，不白屏。
- **导出 / 导入**：导出全量 JSON（含图片）；导入逐条对比、由你决定保留哪一份，绝不默认覆盖。
- **换网址 = 旧数据不可见**：数据绑定当前网址（协议 + 域名 + 端口）。更换域名、改端口或重新发布拿到新地址后，旧网址的数据将读不出来。迁移前请先在原网址「导出备份」，再到新网址「导入备份」；应用启动时也会比对网址并弹提醒。

## 快速开始

```bash
npm run serve        # 零依赖静态服务器 → http://localhost:8123/
```

直接双击 `index.html`（`file://`）无法注册 Service Worker，请用上面的方式本地打开。

首次打开是三步向导：**建学期 → 粘贴班级名单（Excel 一列直接粘，每行一个姓名）→ 开始记录**。之后随时可在 **数据 → 管理名单** 增删。

首次打开就是干净的空班级（只有标签体系与默认作息），不含任何示例数据。仓库里只有站点本身，没有依赖、没有构建产物，clone 下来就是完整可用的应用。
