# 班主任工作台

> 给小学班主任用的**正面管教成长记录**工具。纯前端、离线可用，**数据只存本机、不联网不上传**。

选学生 → 点标签 → 写评语，约 30 秒记一条；可给每张图片写一句说明，期末一键导出**实名**的成长记录文本（打印 / 给家长）。要交给 AI 分析时，改用**脱敏素材**——姓名换成代号，分数、名次、具体日期与他人姓名自动隐去，照片不参与。没有账号、没有后端，不上传任何用户数据；依赖与图标全部为本地资源。

## 功能

| Tab | 能做什么 |
| --- | --- |
| ✍️ **记录** | 选学生 → 点标签 → 写评语，约 30 秒一条；每条最多 6 张图片（拍照 / 相册，可给每张写一句说明）；拍摄规范常驻图片区；时间线分页加载，可切卡片 / 缩略图 / 紧凑版式；草稿自动保存，误退不丢 |
| 🗂️ **班务** | 本班课表（夏 / 冬作息，可选单双周）＋ 我的课表（跨班任教自填）；收缴任务（点姓名即标记已交 / 未交） |
| 📊 **分析** | 生成**要发给 AI 的脱敏素材**——姓名换成一次性代号，分数、名次、具体日期与他人姓名自动隐去，照片不参与；AI 返回的评语可一键还原成真实姓名 |
| 🔒 **数据** | 名单 / 分类 / 标签库管理、学期管理与**归档**（生成备份 .json + 只读报告 .html 两份文件）、**导出备份**（全量 JSON，可导入恢复）、**成长记录文本**（实名纯文本，给人看）、回收站、设置 |

**标签体系**：正面管教 8 个能力分类（各 6 个标签）＋「关注」内部观察分类（问题行为 10 / 错误目的 4 / 鼓励支持 8），共 **70 个预设标签**，分类与标签均可增删改名。

## 数据安全

- **不会自动删除任何数据**：软删的记录先进回收站、保留 30 天；图片只在编辑时移除、记录被彻底删除、或所在学期被「清除本机副本」时才真正删除。
- **归档 = 盖章 + 生成两份文件，不动本机数据**：学期结束时归档，会生成 `班主任工作台_学期名_归档_日期.json`（可导入恢复的全量备份）与同名的 `.html`（自包含、零脚本的只读报告，含图 —— 双击用浏览器打开就能看，也能打印成 PDF）。归档后本机数据照旧；要省空间，再到档案柜点「清除本机副本」（会二次确认，**不可撤销**）。
- **打不开也不会丢数据**：升级只做增量迁移，旧记录缺新字段时按空值补齐，**不删库、不改写已有内容**；万一确实读不出来，应用也不会自动清空数据，而是说明原因并给出出口 —— 独立页面 `recover.html` 不依赖应用代码，能把本机数据直接导成文件。
- **导出 / 导入**：导出全量 JSON（含图片）。导入按情形处理：导入的是**当前学期** → 逐条对比、由你决定保留哪一份，绝不默认覆盖；本机**没有**该学期 → 新建学期并导入全部（换设备恢复走这条）；本机**已有**该学期（含已归档）→ 拒绝导入，因为已归档的学期不在应用内打开，要看就打开它的 `.html` 报告。另有一份**给人看的**「成长记录文本」（实名纯文本、不含照片本体、只读不回填）——它**不是备份**，不能用来恢复。
- **换网址 = 旧数据不可见**：数据绑定当前网址（协议 + 域名 + 端口）。更换域名、改端口或重新发布拿到新地址后，旧网址的数据将读不出来。迁移前请先在原网址「导出备份」，再到新网址「导入备份」；应用启动时也会比对网址并弹提醒。
- **AI 外发只给脱敏内容**：唯一会离开本设备的是你主动复制的「AI 评语素材」——真实姓名换成一次性代号（关掉或刷新即作废），分数、名次、具体日期与他人姓名都会被隐去，照片一张都不发。

## 快速开始

```bash
npm run serve        # 零依赖静态服务器 → http://localhost:8123/
```

直接双击 `index.html`（`file://`）无法注册 Service Worker，请用上面的方式本地打开。

首次打开是三步向导：**建学期 → 粘贴班级名单（Excel 一列直接粘，每行一个姓名）→ 开始记录**。之后随时可在 **数据 → 管理名单** 增删。

首次打开就是干净的空班级（只有标签体系与默认作息），不含任何示例数据。仓库里只有站点本身，没有依赖、没有构建产物，clone 下来就是完整可用的应用。
